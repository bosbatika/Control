01

Что такое EYE

EYE проектируется как язык и среда выполнения, которые могут объединять несколько языков и компонентов в одном приложении.

Свой синтаксис

Объявления через .Start, методы через точку, завершение программы через end, а также сокращение типа с помощью ^.

Типы со своими методами

Тип данных несёт поле value и набор предназначенных ему методов. Компилятор связывает доступные указатели методов при создании переменной.

Многоязычная архитектура

Основная логика генерируется в C. Встроенный модуль net добавляет Go-компонент и мост обмена сообщениями.

IPC через UDS

Go и связующая часть компилятора обмениваются сообщениями через Unix Domain Socket. C-часть взаимодействует через стандартные потоки.

Восстановление частей

По замыслу EYE, отдельные части приложения можно перезапускать после сбоя, не обязательно перезапуская всё приложение целиком.

Расширяемость

К компилятору можно подключать другие языки через дополнительные генераторы и адаптеры обмена сообщениями.

EYE — развивающийся проект. Эта страница описывает синтаксис и механизмы, которые видны в предоставленном ядре, а также архитектурные возможности, заявленные автором.
02

Первый пример

Минимальная программа создаёт целое число, использует метод типа и выводит результат.

hello.eye · пример EYE
import stop_import ;

Int chislo.Start = 12 ;

@ printf("Число: %d\n", chislo.value) ;
@ printf("Чётное? %d\n", chislo.Chet(chislo)) ;

end

В текущей реализации Chet возвращает 1, если число чётное, и 0, если нечётное.

Основы синтаксиса

Программы EYE используют знакомые управляющие конструкции, но собственные правила объявления переменных и вызова внешних функций.

Объявление

Поле value
count.value = count.value + 1 ;

Объявление без начального значения: ~

Если переменной не нужно задавать начальное значение в момент объявления, вместо присваивания через = используется маркер ~. Он означает: объявить переменную, не задавая ей начальное значение в исходной строке.

Объявление без явного начального значения
Int counter.Start ~ ;
String buffer.Start ~ ;
^ nextCounter.Start ~ ;

Сравни: Int counter.Start = 0; задаёт начальное значение явно, а Int counter.Start ~; объявляет переменную без такого присваивания. После объявления значение можно задать через поле .value. Не путай этот маркер с оператором побитового отрицания C.

Условия и циклы

if и for
Int number.Start = 7 ;

if ( number.value > 0 ) {
    @ printf("positive\n") ;
} ;

for ( int i = 0 ; i < 3 ; i = i + 1 ) {
    @ printf("%d\n", i) ;
} ;

end

В предоставленном ядре распознаются управляющие конструкции if, for и switch. Внутри блоков используется синтаксис, близкий к C.

Вызов C-функций

Вызов с префиксом @ передаётся в генерируемый C-код. Например:

Вызов стандартной функции
@ printf("Hello from EYE\n") ;
@ scanf("%d", &count.value) ;

Поле .value

У скалярных типов оно содержит само значение. У String и File это указатель на символьный буфер; у списков — указатель на массив элементов; у Byte — указатель на байты.

Поле .Size

У Byte и типов *_list хранит количество выделенных/доступных элементов согласно операциям выделения и изменения размера.

Внутренний тип: в C-части ядра определён псевдоним Norm как unsigned char. Он используется для элементов Byte, но в таблице автоматической привязки методов отдельного типа EYE Norm нет.
Ниже каталог методов по каждому типу. Имена сохранены в написании ядра, в том числе исторические варианты Size_stirng, Uper, Redect и Nul_stirng.
05

Методы и сокращения типов

При объявлении объекта через .Start ядро обнуляет структуру и привязывает доступные указатели методов соответствующего типа. Вызов выполняется через переменную: object.Method(object, ...) или с адресом, если сигнатура метода принимает указатель.

Пример метода Int
Int chislo.Start = 12 ;
@ printf("Чётное? %d\n", chislo.Chet(chislo)) ;
@ printf("Цифр: %d\n", chislo.Int_length(chislo)) ;

Int — целые числа

Int хранит значение типа C int. Методы позволяют преобразовывать число, сравнивать его, возводить в целую степень, проверять чётность и считать количество цифр.

МетодАргументы после имени методаРезультат и назначение
Float_conv(Int value)Преобразует value.value в float. Внутренняя функция реализации называется Int_to_float.
Max_int(Int value, int other)Сравнивает число с other: возвращает 1, если текущее больше; 0, если равны; -1, если меньше.
Int_to_string(Int value, char buffer[50])Записывает десятичное представление числа в переданный буфер и возвращает указатель на него. Буфер должен вмещать строку и завершающий нулевой символ.
Repeat_int(Int value, int exp)Возвращает число, умноженное само на себя exp раз: фактически value.value в целой степени exp. При exp ≤ 0 текущая реализация возвращает 1.
Chet(Int value)Проверяет чётность. Возвращает 1 для чётного числа и 0 для нечётного.
Int_length(Int value)Возвращает количество цифр в десятичной записи числа. Для 0 возвращает 1; знак минус не считается.
Использование Int
Int number.Start = 125 ;
@ printf("float = %f\n", number.Float_conv(number)) ;
@ printf("compare = %d\n", number.Max_int(number, 100)) ;
@ printf("even = %d\n", number.Chet(number)) ;
@ printf("digits = %d\n", number.Int_length(number)) ;

Float — числа одинарной точности

Float хранит float value. Методы преобразуют его в целое или строку и сравнивают с другим значением.

МетодАргументыРезультат и назначение
Conv_int_min(Float value)Преобразует Float в int обычным приведением C: дробная часть отбрасывается в сторону нуля.
Conv_int_max(Float value)Возвращает округлённое до целого значение через roundf.
Float_to_string(Float value, char buffer[50])Записывает значение в буфер с форматом %f и возвращает указатель на буфер (обычно шесть знаков после точки по правилам printf).
Max_float(Float value, float other)Сравнение: 1 — больше, 0 — равно, -1 — меньше.
Использование Float
Float price.Start = 12.75 ;
@ printf("truncated = %d\n", price.Conv_int_min(price)) ;
@ printf("rounded = %d\n", price.Conv_int_max(price)) ;
@ printf("compare = %d\n", price.Max_float(price, 10.0)) ;

Double — числа двойной точности

Double хранит double value. Набор методов близок к Float, но работает с типом двойной точности.

МетодАргументыРезультат и назначение
Conv_int_min(Double value)Преобразует значение в int с отбрасыванием дробной части в сторону нуля.
Conv_int_max(Double value)Округляет значение до ближайшего целого через round.
String_double(Double value, char buffer[50])Записывает десятичное представление через sprintf(..., "%f", ...). Внутренняя функция реализации называется Double_to_string.
Max_double(Double value, double other)Сравнение: 1 — больше, 0 — равно, -1 — меньше.

String — строки

String содержит char* value. Это C-строка, завершающаяся символом \0. Методы изменения регистра и поиска работают непосредственно с буфером строки.

МетодАргументыРезультат и назначение
Size_stirng(String* value, int size)Выделяет буфер указанного размера, копирует старое содержимое (не более size - 1 байт) и ставит завершающий \0. Написание Size_stirng — точное имя поля API; реализация называется Size_string.
String_to_int(String value)Преобразует начало строки в int через C-функцию atoi.
String_to_float(String value)Преобразует начало строки во float через atof.
Lower(String* value)Меняет латинские символы строки на нижний регистр. Изменяет сам буфер.
Uper(String* value)Меняет латинские символы строки на верхний регистр. Поле называется Uper, а привязанная C-функция — Upper.
Contains(String value, char* substring)Ищет подстроку функцией strstr: возвращает 1, если найдена, и 0, если нет.
Repeat_string(String value, int count)Поле указателя присутствует в структуре String, но в проверенной таблице привязок и реализации ядра метод не подключён. Не вызывай его, пока реализация не добавлена.
Использование String
String title.Start = malloc(128) ;
strcpy(title.value, "Eye Language") ;
@ title.Lower(&title) ;
@ printf("%s\n", title.value) ;
@ printf("contains = %d\n", title.Contains(title, "eye")) ;
@ printf("as int = %d\n", title.String_to_int(title)) ;
Для методов Size_stirng, Lower и Uper сигнатура принимает указатель на String, поэтому при прямом вызове C-функции используется адрес объекта: &title. Для преобразований и Contains передаётся сама структура.

Bool — логические значения

Bool содержит только поле _Bool value. В предоставленной реализации ядра для скалярного Bool не объявлены указатели методов и нет автоматических привязок методов. Значение используют в условиях напрямую.

Использование Bool
Bool ready.Start = 1 ;
if ( ready.value ) {
    @ printf("ready\n") ;
} ;

File — работа с файлами

File содержит указатель value на содержимое и массив name[100] с именем/путём файла. Методы работы с файлом принимают File*, то есть адрес структуры.

МетодАргументыРезультат и назначение
Write_file(File* value)Открывает name в режиме записи "w", записывает строку из value и закрывает файл. Возвращает число записанных символов либо -1, если файл не удалось открыть.
Read_file(File* value)Открывает файл, получает размер через Size_info, выделяет буфер и читает данные функцией fgets. Возвращает 0 при успешном чтении и 1 при ошибке.
Size_info(File* value)Возвращает размер файла в байтах через ftell; при ошибке открытия возвращает -1.
append(File* value, char text[])Открывает файл в режиме добавления "a" и дописывает переданную C-строку в конец. Возвращаемого значения нет.
Вызов File-методов
File logFile.Start ~ ;
strcpy(logFile.name, "app.log") ;
logFile.value = "EYE started\n" ;
@ logFile.Write_file(&logFile) ;
@ printf("size = %ld\n", logFile.Size_info(&logFile)) ;
Режим "w" у Write_file перезаписывает существующий файл. Для дописывания в конец используй append.

Byte — байтовый буфер

Byte хранит Norm* value и количество байтов в Size. В ядре Norm определён как unsigned char. Все методы принимают указатель Byte*.

МетодАргументыРезультат и назначение
Delete_byte(Byte* value)Освобождает буфер, устанавливает value = NULL и Size = 0.
Nul_byte(Byte* value, int count)Освобождает предыдущий буфер, выделяет count нулевых байтов через calloc и записывает количество в Size.
Redect_byte(Byte* value, int count)Изменяет размер буфера через realloc. Это имя API; привязанная функция реализации называется Redirect_byte.
Выделение байтового буфера
Byte payload.Start ~ ;
@ payload.Nul_byte(&payload, 256) ;
@ printf("bytes = %d\n", payload.Size) ;
@ payload.Delete_byte(&payload) ;

Списки: Int_list, Float_list, Double_list, Bool_list, String_list, File_list

Списки — структуры с указателем на массив value и полем Size. У каждого типа списка одинаковый общий шаблон методов: освободить память, выделить новый массив, изменить размер и объединить элементы в одну строку.

Nul_*(List* value, int count)Освобождает старый массив и выделяет новый нулевой массив на count элементов через calloc. Обновляет Size.
Redect_*(List* value, int count)Меняет размер существующего массива через realloc; при успешном изменении обновляет указатель и Size. Внутренние функции реализации называются Redirect_*.

Пример Int_list
Int_list numbers.Start ~ ;
@ numbers.Nul_int(&numbers, 3) ;
numbers.value[0].value = 10 ;
numbers.value[1].value = 20 ;
numbers.value[2].value = 30 ;

Параметр count — количество элементов/байтов, а не последний индекс. После Nul_* допустимые индексы идут от 0 до Size - 1. Результат Join_* — новая выделенная строка; после использования её следует освободить.

Сокращение повторного типа: ^

Символ ^ повторяет последний явно объявленный тип. Это сокращение записи объявления, а не оператор степени.

Оператор ^
Int first.Start = 10 ;
^ second.Start = 20 ;
^ third.Start ~ ;

Float pi.Start = 3.14159 ;
^ radius.Start = 2.5 ;
^ scale.Start ~ ;
После смены типа укажи его явно: например, после группы Int напиши Float, и последующие ^ будут повторять уже Float.

Маркер объявления без присваивания: ~

Если начальное значение не требуется, вместо знака = у объявления .Start ставится ~. Этот вариант полезен, когда поле будет заполнено позднее или память/массив будут подготовлены соответствующим методом.

Явная и отложенная инициализация
Int readyValue.Start = 5 ;
Int inputValue.Start ~ ;
String text.Start ~ ;
Int_list items.Start ~ ;

inputValue.value = 42 ;
text.value = malloc(128) ;
items.Nul_int(&items, 10) ;
Для указательных типов (String, File, Byte и списков) перед использованием нужно подготовить память и указатели. Само объявление через ~ не выделяет буфер автоматически.
06

Импорты и функции для C

Импортная секция располагается в начале программы и завершается маркером import stop_import.

Порядок импортов
import net ;
import my_library ;

@ int twice(int x) {
    return x * 2 ;
} ;

import stop_import ;

Int value.Start = 21 ;
@ printf("%d\n", twice(value.value)) ;

end
  • import my_library; подключает содержимое файла импорта в генерируемый C-код.
  • import net; включает дополнительную Go-часть сетевого runtime.
  • import stop_import; закрывает секцию импортов и начинает тело C-программы.
  • Объявления с префиксом @, расположенные до stop_import, передаются в список C-функций.
Функции, которые должны быть доступны как C-объявления, размещай до import stop_import. После этого маркера записывай исполняемый код программы.

Сетевой модуль net

Встроенный модуль позволяет описывать HTTP-сервер в EYE. Компилятор генерирует Go-обвязку, а обработка пользовательских данных может выполняться в C.

Каркас HTTP-сервера на EYE
import net ;
import stop_import ;

String packet.Start = malloc(4096) ;

for ( ; ; ) {
    if ( fgets(packet.value, 4096, stdin) == NULL ) {
        break ;
    } ;

    if ( strncmp(packet.value, "!value ", 7) == 0 ) {
        printf("$text/plain; charset=utf-8!Привет! Это сервер EYE\n") ;
    } else {
        printf("$ok\n") ;
    } ;

    fflush(stdout) ;
} ;

net_http_server web.Start = "/" ;
net_http_server web.Query ;
net_http_server web.Write ;
net_http_server web.Stop ;
net_http_server web.Where ;
net_http_server web.Listen = "127.0.0.1:8080" ;

end

08

Как общаются языки

Ключевая идея EYE — не заставлять все компоненты писать на одном языке. Runtime связывает процессы разными каналами обмена.

HTTP / GoПолучает запрос и формирует сообщение
UDSUnix Domain Socket между Go и мостом
Мост ядраПересылает данные между каналами
stdin / stdoutПотоки ввода и вывода процесса C
C / EYEВыполняет пользовательскую логику

Важно: C не подключается к UDS

C получает сообщения через стандартный ввод (`stdin`) и отправляет ответы через стандартный вывод (`stdout`). UDS используется на стороне Go и моста ядра.

Маркер ответа $

Мост распознаёт строки C, начинающиеся с $, убирает префикс и передаёт содержимое обратно в Go через UDS.

Протокол HTTP-ответа

Для обработки запроса C читает строку из stdin. На обычный запрос можно вернуть подтверждение $ok. Для команды ответа !value C отправляет тип содержимого и тело через разделитель !.

Формат ответа со стороны C
if ( strncmp(packet.value, "!value ", 7) == 0 ) {
    printf("$text/plain; charset=utf-8!Ответ из EYE\n") ;
} else {
    printf("$ok\n") ;
} ;
fflush(stdout) ;
`Write` на Go-стороне отправляет запрос `!value`, получает строку формата `Content-Type!body`, устанавливает HTTP-заголовок и записывает тело клиенту.

Подключение других языков

По архитектуре проекта к компилятору можно подключать дополнительные языки. Для нового языка требуется соответствующий генератор/адаптер запуска и согласованный протокол сообщений. UDS — один из способов межпроцессного взаимодействия. Само наличие UDS не означает, что произвольный язык подключается автоматически без адаптера.

09

Отказоустойчивость и перезапуск частей

Автор EYE описывает модель восстановления, близкую по идее к подходу Elixir: при сбое можно перезапускать отдельные части приложения.

Изоляция частей

Приложение можно организовывать из отдельных компонентов, чтобы сбой одного компонента не обязательно останавливал всё приложение.

Перезапуск

Runtime ориентирован на восстановление упавших частей путём повторного запуска, а не только на единый перезапуск всего процесса.

Внешние процессы

Архитектура с несколькими языками и каналами IPC позволяет разделять обязанности между отдельными процессами.

Это описание отражает заявленную концепцию EYE. В предоставленном исходнике не найден полный пользовательский синтаксис дерева супервизоров, стратегий перезапуска и политик интенсивности рестартов. Поэтому здесь не приводится вымышленный пример таких директив.

Сходство с Elixir — концептуальное: идея восстановления отдельных частей. Это не означает совместимость с OTP или идентичную реализацию супервизоров.

10

Компиляция и запуск

Компилятор читает файл .eye, генерирует C-код и при включённом import net — Go-компонент.

1 · EYEИсходный файл `.eye`
2 · ParserТокенизация и разбор
3 · CГенерация и сборка C
4 · GoГенерация и сборка при `net`
5 · RuntimeЗапуск процессов и мостов

Запросы компилятора

  1. Имя выходного C-файла.
  2. Дополнительная команда или команды, если они нужны.
  3. Время работы программы.
  4. Имя исходного файла `.eye`.
  5. Имя Go-файла, если подключён `import net`.

В текущей реализации для сборки C используется компилятор GCC; для сетевого компонента — Go toolchain. При использовании математических функций ядро связывает математическую библиотеку.

Режимы запуска и поведение мостов зависят от версии ядра. Используй согласованную версию компилятора и runtime; не смешивай файлы ядра из разных итераций разработки.
